# 📊 Digital Marketing Campaign Analysis

Data cleaning, preprocessing and exploratory analysis of digital marketing campaigns using Python.

This project was developed as the final project for the **Data Processing with Python** module in the Technolochicas program.

---

## 📌 Project Overview

Marketing agencies receive campaign reports from multiple advertising platforms such as Facebook Ads, Google Ads, TikTok Ads, LinkedIn Ads and others.

These reports often contain:

- Duplicate records
- Missing values
- Inconsistent date formats
- Incorrect text formatting
- Negative values caused by data entry errors

The objective of this project is to transform raw data into reliable information that supports business decisions.

---

## 🎯 Objectives

- Clean inconsistent datasets
- Handle missing values
- Normalize dates and text fields
- Calculate marketing KPIs
- Generate business insights
- Visualize campaign performance

---

## 🛠 Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

---

## 📈 KPIs Calculated

- CTR (Click Through Rate)
- Conversion Rate
- CPA (Cost per Acquisition)
- ROAS (Return on Advertising Spend)
- ROI
- Profit

---

## 📊 Data Cleaning

The project includes:

- Duplicate removal
- Date normalization
- Text standardization
- Missing value imputation
- Negative value correction
- Feature engineering

---

## 📉 Visualizations

The notebook generates:

- Average ROAS by platform
- Monthly Spend vs Revenue
- Campaign Performance Distribution
- Conversion Rate by Age Segment

---

## 📌 Main Findings

- Instagram Ads achieved the highest average ROAS.
- Google Ads also showed strong profitability.
- More than 40% of campaigns achieved excellent performance.
- Some campaigns generated negative profit and should be reviewed.
